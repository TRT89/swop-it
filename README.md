# Swop-it

A local sharing marketplace where neighbours lend products and exchange skills,
paid for with **Social Points (SP)** instead of money.

> Full documentation is added as the phases land. Quick start:
>
> ```bash
> npm install
> npm run dev      # migrates + seeds the database, then starts on :3000
> ```
>
> Log in with `demo@swop-it.local` / `swopit123`.
